Team Throughput (final resolutions vs. total stage completions, resting/working/available ticks)

"Final resolutions" only credits the team that closed out a multi-stage incident's last leg. "Stage completions" counts every leg any team handed off (e.g. Perimeter clearing a structural collapse before Medical takes over) — use this one to see who's actually doing work.

Live Throughput (updates as the run happens — cumulative, sim-authoritative counters)

Streamed from every tick, not the end-of-run summary. Reconciled against the final diagnostics when the run completes — a mismatch there is shown, not hidden. Moved here from the Live Ops tab so that tab fits on one screen; still updates live while a run streams.

Radio (virtual peer bus)

Cumulative counters from vbus_get_stats(), reported once per tick. Moved here from Live Ops, which only needs the per-receiver loss % (shown in its topbar) - full stats live here where there's room. "Channel busy %" is the average share of each tick's 36s of mission time the radio spent transmitting, over the whole run so far - not an instantaneous reading.
