# Docs index

Design docs, board bring-up, evaluation results, and research notes for
the `tron` / REMCE rescue-coordination system. Start at the repo root
[`README.md`](../README.md) for the project overview and quick start.

## In `docs/`

- [`DK_DEMO_LAUNCH.md`](DK_DEMO_LAUNCH.md) — STM32N6570-DK boot mode
  (DEV/`DevRam`), boot switches, and demo-pace guidance.
- [`evaluation/README.md`](evaluation/README.md) — the consensus/AI
  evaluation harness (`make evaluate`): what it measures and how to run it.
- [`evaluation/RESULTS.md`](evaluation/RESULTS.md) — latest evaluation
  results, regenerated by `make evaluate`.
- [`research/feature_contract_research.md`](research/feature_contract_research.md)
  — research behind the AI fault predictor's feature contract.
- [`research/peer_fault_detection_prior_art.md`](research/peer_fault_detection_prior_art.md)
  — prior art survey for peer-based fault detection.
- [`research/feature_contract_experiments/`](research/feature_contract_experiments/)
  — the experiment scripts and results backing the feature-contract research.
